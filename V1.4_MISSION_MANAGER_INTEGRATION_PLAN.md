## 🎯 KẾ HOẠCH THỰC THI (3 PHASES)

### Phase 1: Chuẩn bị (LOW RISK)
**Mục tiêu**: Thêm config variables vào main_sim.m mà không thay đổi behavior

**Bước 1.1**: Thêm MISSION_TYPE config
```matlab
% --- C. CHỌN QUỸ ĐẠO NHIỆM VỤ (MISSION TYPE) ---
% 0: Waypoint tĩnh (Giữ nguyên cấu hình cũ)
% 1: QUỸ ĐẠO MẮT BÃO (ORBIT WITH CENTER-FOCUS YAW)
% 2: CUA NGANG (STRAFING / CRAB WALK)
% 3: BAY THẲNG + ROLL DAO ĐỘNG (±90 DEG)
MISSION_TYPE = 0;  % ← DEFAULT = 0 để giữ behavior cũ
```

**Bước 1.2**: Thêm mission_params struct
```matlab
% Tùy chỉnh thông số quỹ đạo
mission_params.v_forward = 2.0;  % Vận tốc tiến (m/s)
mission_params.radius    = 5.0;  % Biên độ (m)
mission_params.omega     = 0.4;  % Tần số góc (rad/s)
mission_params.z_base    = -5.0; % Độ cao (m)
```

**Bước 1.3**: Cập nhật call mission_manager
```matlab
% Từ: raw_target = mission_manager(t);
% Thành:
raw_target = mission_manager(t, MISSION_TYPE, mission_params);
```

**Risk**: 🟢 LOW - Default MISSION_TYPE=0 giữ nguyên behavior cũ
