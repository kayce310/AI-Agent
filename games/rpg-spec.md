# RPG Game Specification

## Features Required:
1. 5 Maps: forest, desert, ice, volcano, void with portals
2. Story: intro, NPC, 5+ quests  
3. 4 Classes: Warrior, Mage, Ranger, Assassin
4. Equipment: Weapon, Armor, Helmet, Boots, Ring, Amulet with random stats + rarity
5. Upgrade/Crafting system
6. Boss: wave (5), world boss (25), hidden boss
7. Puzzle: levers, secret rooms
8. Arena: PvP, leaderboard
9. Fashion: cosmetics
10. Level scaling
