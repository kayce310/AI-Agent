### VẤN ĐỀ #5: Hologram errors hidden, no interaction

**Architecture:** readouts.errors tracked nhưng không display
**Frontend:** Zero mousewheel/drag handlers, zero keyboard shortcuts
**Impact:** Silent failures, user không biết có lỗi

```
PHÁT HIỆN: Hologram errors silently tracked, no zoom/rotate interaction
ĐỀ XUẤT:
  1. Add error modal when readouts.errors > 0
  2. Add wheel handler (zoom), drag handler (rotate)
  3. Add keyboard shortcuts (arrows for rotate, +/- for zoom)
ƯU TIÊN: 1 (critical)
ĐIỂM: 5/10 (complex)
THỜI GIAN: 45-60 phút
```

### VẤN ĐỀ #8: Dark theme incomplete, no responsive

**Theme:** Light theme CSS not defined, toggle handler may be missing
**Responsive:** No media queries, fixed sizes (360px, 700px), no wrap
**WCAG:** Dark-only violates accessibility

```
PHÁT HIỆN: Light theme missing, responsive design absent
ĐỀ XUẤT:
  1. Define :root[data-theme="light"] CSS variables
  2. Add media queries (1024px, 768px breakpoints)
  3. Wire theme toggle: localStorage + data-theme attribute
  4. Make canvas responsive: calc() instead of px
  5. Tab wrap on mobile
ƯU TIÊN: 2 (production readiness)
ĐIỂM: 5/10
THỜI GIAN: 1.5-2 hours
```
